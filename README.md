# Learn PyTorch

A Jupyter notebook for learning PyTorch fundamentals, including:
- Tensor creation and manipulation
- GPU acceleration with CUDA
- Basic PyTorch operations
- Working with different data types and shapes

## Requirements
- Python 3.11+
- PyTorch 2.5.1+
- CUDA support (optional, for GPU acceleration)

## Usage
Open `tesnors.ipynb` in Jupyter Notebook or VS Code to explore PyTorch basics.
